# Tactical sources (bibliography)

Every layer-1 ("tactically optimal") behaviour in the match engine must trace back to coach-education material listed here, via the principle catalog in [`principles.md`](principles.md).
Source keys like `[FIFA-EFI]` are used throughout the catalog.

**Access** means: `open` = freely readable; `partial` = only partly readable (third-party copy, paywall, or too large for tooling); `none` = could not be accessed (listed so the gap is visible).
